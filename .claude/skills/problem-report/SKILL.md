# Problem Report

อ่านไฟล์หรือรันคำสั่งแบบ read-only เพื่อหา root cause ได้
ห้ามแก้โค้ดจนกว่า user จะพิมพ์ "ตกลง"

## Format

### 1. ปัญหา
อาการที่เจอ ถ้ามี error ให้ quote ตรงตัว

### 2. สาเหตุ
root cause ไม่ใช่อาการ ระบุ `ไฟล์:บรรทัด`

### 3. วิธีแก้
อย่างน้อย 2 ทาง แต่ละทางมี:
- **ข้อดี:**
- **ข้อเสีย:**
- **pseudo code:**
  ```
  ...
  ```

### 4. วิธีที่แนะนำ
เลือก 1 ทาง พร้อมเหตุผลสั้นๆ

### 5. แหล่งอ้างอิง
- `path/file.ext:123`
- docs/URL

---
พิมพ์ "ตกลง" เพื่อลงมือ หรือบอกเลขวิธีที่ต้องการ
